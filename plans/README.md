# 公開課表

放在這個資料夾的每一個 `.json` 檔，都會出現在網站「查看已儲存的課表」清單裡，
標成 **公開**，任何人打開網站都看得到、可以點開來參考。

## 怎麼放一份進來

1. 在網站上排好課，右上角按 **匯出備份** → 會下載一個 `學號.json`。
2. 到這個 repo 的 `plans/` 資料夾 → **Add file → Upload files** → 把那個 json 丟進來 → Commit。
3. 一分鐘後重新整理網站，清單裡就有了。

檔名就是識別用的，建議用學號或姓名（例如 `11321001.json`）。

## 檔案長什麼樣

```json
{
  "name": "莊家焮",
  "sid": "11321001",
  "cohort": 113,
  "done": 20,
  "plan": 9,
  "updatedAt": 1757000000000,
  "profile": { "name": "莊家焮", "sid": "11321001", "cohort": 113 },
  "place":  { "k5#1": "s113-1", "k5#2": "s113-2" },
  "cat": {}, "doneOv": {}, "custom": [], "check": {}
}
```

網站是用 GitHub 的公開 API 讀這個資料夾的，不需要任何金鑰。

## 要刪掉一份

直接在 GitHub 上刪掉那個 json 檔就好。網站每個瀏覽階段會快取 10 分鐘，
所以刪完可能要等一下或重開分頁才會消失。

## 隱私提醒

這是**公開** repo，放進來的姓名、學號和修課紀錄任何人都看得到。
不想公開的就別放這裡 —— 在網站上按「儲存課表」只會存在自己的瀏覽器裡。
